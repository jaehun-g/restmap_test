# 휴게소·EX 주유소 통합 E2E QA

기준일: 2026-10-20

## 범위

- 휴게소 중심 통합 화면이 서버에서 렌더링되는지 확인한다.
- EX 전용 Supabase 조회가 GS 데이터를 포함하지 않는지 확인한다.
- 선택 노선의 하이라이트 경로가 실제 좌표 배열로 응답하는지 확인한다.
- 자동 결합의 이름·노선·방향·300m 기준은 `tests/facility-places.test.mts`에서 별도로 확인한다.

## 실행 방법

개발 서버를 먼저 실행한 뒤 다음을 실행한다.

```powershell
node scripts/run-facility-map-e2e.mjs
```

기본 대상은 `http://127.0.0.1:3003`이며, 다른 서버는 `E2E_BASE_URL` 환경 변수로 지정한다.

## 체크리스트

- [x] `/mobile`이 200으로 응답하고 `휴게소 · EX 주유소` 통합 제어 문구를 렌더링한다.
- [x] `/api/rest-areas`가 휴게소 목록을 반환한다.
- [x] `/api/gas-stations?source=ex&routeName=경부선`이 EX 주유소만 반환한다.
- [x] `/api/highway-routes?routeName=경부선`이 2개 이상 점을 가진 선형 배열을 반환한다.
- [x] 자동 결합의 반대 방향·다른 노선·300m 초과 제외와 중복 휴게소 최근접 연결을 단위 테스트로 확인한다.
- [x] Chromium Playwright에서 경부선 선택, 서울/부산 방향 선택, 죽전(서울 방향) EX 주유소 통합 상세를 확인한다.
- [x] Chromium Playwright에서 관리자 경부선·서울 방향 필터가 반대 방향 행을 제거하는지 확인한다.
- [ ] 카카오 지도 SDK가 테스트 브라우저에서 로드된 뒤 개별 마커, 클러스터 비활성화, 노선 선형을 시각 회귀 대상으로 확인한다. 현재 JavaScript 키/도메인 등록 또는 네트워크 문제로 SDK 로드 실패.
