- 원본 출처: https://www.data.go.kr/data/15043716/fileData.do

- 대조 기준: 휴게소명과 방향을 정규화한 뒤 일치하는 DB 후보가 하나일 때 연결한다. CSV 노선명이 달라도 기존 DB 노선명을 유지한다.
- `양방향`·`양방`·`통합`·`통합방향`은 동일한 방향으로 비교한다. 방향 미표기 CSV는 단일 양방향 후보만 포함한다.
- 2026-11-13 한국시간 기준 원본 215행 모두 저장. DB 247행 중 대형 주차 대수가 없는 항목은 32건이다.
- 원본 CSV는 수정하지 않았으며, 기존 주차 대수 201건과 DB 노선을 유지하고 미매핑 항목 13건을 추가 저장했다.
