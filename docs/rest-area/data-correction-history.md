# 데이터 보정 작업 요약

기존 완료 보고서를 작업 단위로 묶은 기록이다. 상세 변경 이력은 Git 기록과 남겨 둔 백업 데이터를 참고한다.

## 휴게소와 주유소

- **2026-10-21 · 양방향 표기 통일:** 통합·양방향 휴게소 14곳의 이름과 방향 표시를 양방향으로 정리했다.
- **2026-10-22 · 주유소 좌표 보정:** 휴게소와 이름·방향·노선이 일치하는 유일 후보 21곳의 좌표를 보정하고 동기화 시에도 보정값을 유지하도록 했다. 변경 전 좌표와 원천 코드는 [백업 JSON](../station-coordinate-corrections-1792645901470.json)에 남겼다.
- **2026-10-22 · 양북임시·부안 방향 보정:** 양북임시는 울산·포항 방향, 부안은 서울·목포 방향으로 이름과 방향 필드를 보정했다. 표준 코드와 ID, 좌표는 유지했다.
- **2026-10-22 · 민자 휴게소 제외:** 확인된 23곳을 서비스에서 제외하고 재수집 차단 목록과 음식정보 연결을 정리했다.
- **2026-11-09 · 휴게소·주유소 연결 보정:** 영덕·포항·김제 양방향 및 의왕청계·서하남의 이름·방향·좌표 보정과 연결을 반영했다. 당시 EX 주유소 226곳 중 223곳이 로컬 매칭 규칙에서 연결됐다.
- **2026-11-12 확인 · 김해금관가야:** 현재 로컬 매칭 규칙과 DB에서 창원·기장 주유소가 모두 양방향 휴게소에 연결된다. 확인 시점에 EX 주유소 226곳 중 224곳이 연결됐다.
- **밀양영남루 위치·방향 보정:** 휴게소 양방향 좌표와 연결 주유소 위치를 보정하고 표시 방향 및 동기화 별칭을 정리했다. 밀양 방향으로 표시한 시설의 실제 진입 방향은 추가 확인이 필요하다.
