# 고속도로 노선 하이라이트 QA

점검일: 2026-10-20
점검 대상: `test_highway_routes.path_coordinates` 및 카카오 지도 노선 하이라이트

## 판정 기준

- 좌표는 앱 내부 형식인 `[위도, 경도]`이어야 한다.
- 선택한 노선의 휴게소 좌표는 해당 선형에서 2km 이내여야 한다.
- 각 경로는 실제 도로의 굴곡을 충분히 따를 만큼 조밀해야 한다. 인접 점 간격이 1km를 넘는 구간은 시각 점검 대상으로 분류한다.
- 노선마다 고유한 선형이 있고, `path_coordinates`가 비어 있지 않아야 한다.
- 지도 SDK가 다중 경로를 분리된 선으로 렌더링해야 한다.

### 원본 데이터 추적성이란

`path_coordinates`의 각 값이 **어느 기관·데이터셋의 어느 버전에서, 언제 수집되어, 어떤 노선 식별자와 변환 규칙을 거쳐 DB에 들어왔는지** 재현할 수 있는 상태를 말한다. 선형 오류가 발견됐을 때 원본을 다시 받아 수정하고, 변경 영향과 사용 조건을 검토하기 위해 필요하다.

현재 프로젝트는 과거 커밋의 `public/data/export.json`에 GeoJSON 사본만 남아 있다. 다음 정보가 없어 추적성이 실패 상태다.

- 원본 제공 기관·URL·라이선스
- 수집 일시와 데이터 버전 또는 스냅샷 식별자
- 원본 피처 ID 및 공식 노선 ID
- 원본 노선명에서 앱의 `route_name`으로 바꾼 매핑표
- GeoJSON의 `[경도, 위도]`를 DB의 `[위도, 경도]`로 변환하고 적재한 스크립트
- 적재 전후 검증 결과와 갱신 이력

## 재검증 방법

1. `test_highway_routes`에서 각 경로의 모든 인접 점 간 거리를 계산한다.
2. `test_lounge`의 좌표가 있는 휴게소를 같은 `route_name`의 경로와 비교해 최소 거리를 계산한다.
3. 동일한 `path_coordinates` 해시와 `NULL` 경로를 조회한다.
4. 실제 카카오 지도에서 노선을 선택하고, 위의 시각 점검 대상 노선을 확대해 타일 도로선과 겹치는지 확인한다.

## 완료 조건

모든 선택 가능한 노선에 경로가 있고, 서로 다른 노선이 같은 선형을 공유하지 않으며, 경계값이 경로에서 계산되고, 고정밀 원본 데이터 및 실제 지도 중첩 확인으로 굴곡 구간의 이탈이 해소되면 이 QA를 통과로 변경한다.
