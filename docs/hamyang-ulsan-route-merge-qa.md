# 함양울산선 노선명 통합 QA

확인일: 2026-10-20

## 통합 기준

- 표준명: `함양울산선`
- 호환 별칭: `밀양울산선`
- 대상 선형: 고속국도 제14호선, `path_coordinates` 4개 경로

## DB 적용 결과

- [x] `밀양울산선`(id 10)과 `함양울산선`(id 28)의 노선번호가 모두 14이고, `path_coordinates` 해시가 동일함을 트랜잭션 시작 전에 확인했다.
- [x] `test_lounge`의 울주 휴게소 2건(id 197, 198)을 `함양울산선`으로 변경했다.
- [x] 밀양영남루 2건을 포함해 `함양울산선` 휴게소는 총 4건으로 집계된다.
- [x] 중복 `test_highway_routes` 행 `밀양울산선`(id 10)을 삭제하고 `함양울산선`(id 28)만 유지했다.

## 호환성과 렌더링 경로

- [x] `밀양울산선`을 포함한 기존 노선 API 요청은 `함양울산선` 선형(id 28)을 반환한다.
- [x] 휴게소 필터와 노선 선택지는 별칭을 합산해 `함양울산선` 하나로 표시한다.
- [x] EX 주유소 원천 테이블의 `밀양울산선` 값은 외부 동기화 보호를 위해 보존하되, 화면 모델에서 표준명으로 정규화한다.
- [x] 지도 하이라이트와 뷰포트 비교도 별칭을 같은 노선으로 판단한다.
- [x] API 확인: 별칭/표준명 요청은 같은 route id와 경로 수를 반환했고, 주유소는 각각 8건으로 동일했다.

## 재실행 및 추적성

- 스크립트: `node scripts/merge-highway-route-alias.mjs`는 드라이런이며, 실제 적용은 `node --env-file=.env.local scripts/merge-highway-route-alias.mjs --apply`이다.
- 스크립트는 두 노선의 노선번호와 선형 해시, 별칭 휴게소 수를 먼저 검증한다. 조건이 맞지 않으면 롤백한다.
- 원본 EX 동기화 데이터는 변경하지 않으므로, 원천 명칭과 앱 표준명 간의 매핑은 `lib/highway-route-name.ts`에서 추적한다.
