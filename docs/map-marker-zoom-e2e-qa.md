# 지도 마커 레벨 전환 E2E QA

기준일: 2026-10-20

## 확인 항목

- [x] 기본 지도에서 클러스터러가 모든 마커를 `nodraw=true`로 일괄 등록한 뒤 한 번만 다시 그린다.
- [x] 지도 레벨을 변경해도 같은 마커 집합은 다시 생성하지 않는다.
- [x] `e2e/kakao-map-zoom.spec.ts`가 위 두 동작을 Kakao SDK 목으로 검증한다.
- [ ] 실제 Kakao SDK에서 클러스터 아이콘이 전환되는 화면은 JavaScript 키의 테스트 도메인 등록 또는 네트워크 연결 복구 후 확인한다.

## 실행

```powershell
npm.cmd run e2e:visual
```

실제 SDK의 키·도메인 제약과 무관하게 회귀를 재현하기 위해, 해당 테스트는 브라우저 시작 전 Kakao Maps SDK 목을 주입한다. 마커 생성 수가 지도 레벨 변경 뒤 증가하면 실패한다.
