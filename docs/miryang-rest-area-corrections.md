# 밀양영남루 휴게소 위치와 표시 방향 보정

카카오 장소 검색에서 함양 방향 휴게소는 함양울산고속도로 87-1, 밀양 방향 휴게소는 88에 위치한다. 기존 휴게소 좌표는 두 시설의 반대편에 있어 각각 35.4920483, 128.6643574와 35.4894626, 128.6643041을 기준으로 보정했다. `test_lounge`의 real 자료형 정밀도에 따라 저장 좌표는 반올림될 수 있다.

표준 코드 000602의 표시 이름과 방향은 사용자 요청에 따라 밀양 방향으로 변경했다. 원천에는 같은 주소의 시설이 울산 방향으로도 표시되므로 동기화 시 기존 이름을 별칭으로 인식한다. 실제 진입 방향은 별도 확인이 필요하다.

울산 명칭을 사용하는 동일 주소의 EX 주유소는 기존에 잘못된 휴게소 좌표를 따르도록 설정되어 있어 밀양 방향 휴게소 위치로 함께 보정했다. 원천 주유소 이름은 유지한다.
