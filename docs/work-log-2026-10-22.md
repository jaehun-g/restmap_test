## 지도 조작 오류 수정

확대·축소 중 데이터를 순차 반영하면서 클러스터가 잠시 개별 마커로 보이거나 깜빡이는 문제를 수정했다. 반경을 줄일 때는 메모리에 있는 데이터로 반경 밖 마커를 즉시 제외하고, 반경을 넓힐 때는 추가 데이터 수신까지 기다리도록 처리했다.

전체화면 진입 시 지도 크기를 다시 계산해 외곽 흰 여백을 줄였다. 자동 영역 맞춤은 전체화면 진입 시점에 수행하도록 제한해, 선택 상태 변경 때 사용자가 설정한 줌이 되돌아가지 않도록 했다. 관리자 상세 모달은 전체화면 요소 안에 표시되도록 Portal 대상을 조정했으며, 클러스터 확대를 프로그램에 의한 지도 이동으로 처리해 확대 후 마커가 사라지는 문제를 보완했다.

주요 변경 파일: [kakao-map.tsx](../components/kakao-map.tsx), [admin-detail-modal.tsx](../components/admin-detail-modal.tsx), [kakao-place-markers.ts](../lib/kakao-place-markers.ts).

## 지도 조회와 마커 갱신 성능 개선

초기 휴게소 조회에서 화면에 사용하지 않는 음식 메뉴 전체 집계를 제거했다. 음식 메뉴는 상세 음식 탭에서 해당 휴게소 데이터만 조회한다. 최초 주유소 요청의 고정 150ms 대기를 제거하고, 재조회 중에는 기존 휴게소 데이터를 유지하도록 했다.

서버는 휴게소·주유소 공통 스냅샷을 캐시하며, 60초 후 재검증하고 120초 이후에는 갱신된 데이터를 기다린다. 주유소 검색 결과의 브라우저 메모리 캐시는 30초·최대 20개 범위로 제한했다. 관리자 조회와 명시적인 최신 조회는 서버 캐시를 우회하고, 앱 내 저장·동기화 성공 시 관련 캐시 태그를 만료시킨다.

마커 갱신에서는 기존 레이어·클러스터러·유지되는 마커 객체를 재사용하고, 추가·삭제·좌표·아이콘 등이 달라진 항목만 반영한다. 상세정보 클릭은 최신 레코드를 참조하며, 휴게소별 주유소 연결 목록은 Map 인덱스로 공유한다.

| API | 캐시 조회 | 최신 DB 조회 |
| --- | ---: | ---: |
| 휴게소 조회 | 10ms | 94ms |
| EX 주유소 조회 | 9ms | 87ms |

위 값은 실제 Supabase DB를 사용한 로컬 프로덕션 서버의 단일 측정 예시다. 배포환경의 렌더링 속도 개선율을 뜻하지 않으며, 배포 후 API 응답 시간과 첫 마커 표시 시간은 별도로 측정해야 한다.

주요 변경 파일: [cached-map-queries.ts](../lib/cached-map-queries.ts), [query-cache.ts](../lib/query-cache.ts), [kakao-place-markers.ts](../lib/kakao-place-markers.ts). 상세 검증은 [성능 개선 기록](./map-rendering-performance.md)에 정리했다.

## 휴게소와 주유소 연결 및 유가 표시 개선

양방향 휴게소에 여러 방향의 주유소를 연결하고, 바텀시트·모달에서 연결된 주유소 목록과 개별 가격을 확인할 수 있도록 했다. 개별 주유소의 지도 정보로 이동하는 동작도 연결했다. 휘발유·경유 가격은 같으면 단일 가격, 다르면 최저가부터 최고가까지 범위로 표시하며 일부 가격이 없으면 미확인 상태를 안내한다.

원천 방향 필드로 연결할 후보가 없을 때 주유소 이름의 괄호 안 방향을 사용하는 보조 매칭을 추가했다. 노선·명칭·좌표·300m 이내 거리 검증은 유지한다. 연결된 단방향 휴게소의 방향을 필터에 적용해, 원천 주유소 방향 필드가 달라도 연결 시설이 검색에서 분리되지 않도록 했다.

사용자가 확인한 옥천만남·행담도·마장 등의 명칭 예외를 원천 코드별로 반영하고, 처인·고삼호수의 주유소 방향을 보완했다. 행담도(목포)·고삼호수(포천)의 주소·좌표를 보정했으며, 이후 정정에 따라 이천(남이)주유소는 마장 대신 이천(남이 방향) 휴게소에 연결했다. 마장복합(상)주유소는 마장 연결을 유지한다.

거리만 초과하고 동명·동방향·동일 노선 등 나머지 검증을 통과한 주유소 21곳의 좌표를 대응 휴게소와 동일하게 변경했다. 이미 다른 휴게소에 연결되거나 대상이 모호한 후보는 제외했다. 좌표 보정 후 새로 주유소가 연결된 단방향 휴게소는 20곳이다. 보정값은 EX 주유소 동기화에서도 유지하도록 했다.

주요 변경 파일: [facility-places.ts](../lib/facility-places.ts), [facility-filters.ts](../lib/facility-filters.ts), [rest-area-prices.ts](../lib/rest-area-prices.ts), [verified-rest-area-stations.ts](../lib/verified-rest-area-stations.ts), [ex-station-sync.ts](../lib/ex-station-sync.ts). 변경 전후 좌표는 [좌표 보정 기록](./station-coordinate-corrections.md)에 남겼다.

## 민자 구간 휴게소 제외

전체 휴게소를 대조해 민자 구간 시설 23곳을 `test_lounge`에서 삭제했다. 전체 휴게소는 270곳에서 247곳으로 줄었다. 해당 시설은 모두 기존 CSV 215곳 이후 통합 과정에서 추가된 데이터이며, 기존 215곳은 유지했다.

혼합 노선은 시설 단위로 제외해 같은 노선의 공영 구간 휴게소를 유지했다. 관련 음식정보 매핑 21건을 미연결로 바꾸고 후보 ID를 정리했으며, 수집된 원본 메뉴는 보존했다. 삭제 전 백업으로 매핑을 재검증한 결과, 삭제한 시설에 연결된 EX 주유소는 0곳이었다.

표준 코드로 API 재추가를 막고 CSV에서도 시설명·노선을 확인해 제외하도록 했다. 원천 API에 민자 여부 구분이 없어, 현재 제외 정책은 확인한 23곳에 대한 명시적 목록이다. 새 민자 시설이 수집되면 목록 검토가 필요하다.

주요 변경 파일: [excluded-private-rest-areas.ts](../lib/excluded-private-rest-areas.ts), [rest-area-integration.ts](../lib/rest-area-integration.ts), [remove-private-rest-areas.mjs](../scripts/remove-private-rest-areas.mjs). 대상·백업 정보는 [삭제 기록](./private-rest-area-removal.md)에 정리했다.

이미 연결됐지만 주유소 이름 방향과 원천 방향 필드가 충돌하는 선산·문경·서여주·부여백제·밀양영남루의 5건도 별도 검증 대상으로 남아 있다. 현재 로직은 방향 필드로 연결할 후보가 있으면 이름 방향보다 우선하므로, 9건의 미매칭과 5건의 연결 재검증을 구분해 처리해야 한다.

최신 휴게소별 후보와 집계는 [미매핑 검증표](./directed-rest-area-station-review.md)를 참고한다. 다음 작업은 방향 보정 변경사항 커밋, 14건의 연결 검증, 배포환경 지도 성능 측정이다.
