## 표시 정책

- 검색·필터에 맞고 유효 좌표가 있는 장소는 개별 마커, 동일 좌표 그룹 또는 공간 클러스터 중 하나로 표시한다.
- 원래 동일 휴게소로 연결되는 주유소는 검색 때문에 다른 마커로 분리하지 않는다.
- 선택 중 줌은 선택 마커를 가시 영역에 유지한다. 드래그 또는 선택 해제 후에는 선택 장소를 따라가는 카메라 보정을 중단한다.
- 검색·방향·거리 조건에서 제외되거나 좌표가 없는 장소는 의도된 제외이며 마커 누락으로 판정하지 않는다.
- 노선 선택 시 기존 거리 범위 제한을 건너뛰고, 노선·방향 등 나머지 조건은 유지한다.

## 실행 결과와 재현 방법

- 실제 Kakao SDK E2E: **10개 통과**. 휴게소·주유소 응답은 고정 테스트 데이터이며 SDK와 클러스터러 동작은 실제 구현을 사용한다.
- 단위 테스트: 시설 통합·필터·마커·클러스터 표시 서명·위치·노선 범위 관련 **71개 통과**.
- 기존 SDK 모의 E2E: 줌 재조회·음식정보 표시 **2개 통과**. 프로덕션 빌드를 격리 서버에서 실행해 확인했다.
- 변경 파일 ESLint, TypeScript 및 프로덕션 빌드 통과.
- 실제 SDK E2E는 생성 횟수만 보지 않고 `getMap()`, 살아 있는 클러스터의 구성원, 선택 아이콘의 실제 DOM 사각형을 검사한다.
- 실제 SDK 실행 주소: `http://localhost:3000`. 격리 프로덕션 포트의 SDK 요청은 `ERR_BLOCKED_BY_ORB`로 거절되어 실제 SDK 검증은 정상 로드되는 등록 주소에서 진행했다. 운영 도메인의 배포 후 검증은 별도 항목이다.

앱을 Kakao에 등록된 주소에서 실행한 뒤:

```powershell
npm.cmd run e2e:marker-visibility
```

다른 등록 주소를 사용하려면:

```powershell
$env:E2E_BASE_URL = 'http://localhost:3000'
npm.cmd run e2e:marker-visibility
```

실제 SDK 검증은 `E2E_LIVE_KAKAO=1`일 때만 실행된다. 위 전용 명령이 이 값을 설정하며, 일반 모의 SDK 테스트에서는 외부 SDK 호출을 요구하지 않는다. 스크린샷은 Playwright의 `test-results` 아래 `admin-list-selection-zoom.png`, `mobile-list-selection-zoom.png` 등에 생성된다.

단위 테스트 명령:

```powershell
node --test tests/facility-filters.test.mts tests/facility-places.test.mts tests/kakao-markers.test.mts tests/filters.test.mts tests/kakao-location.test.mts tests/gas-stations.test.mts tests/marker-layer.test.mts tests/marker-layer-appearance.test.mts tests/mobile-route-search.test.mts
```
