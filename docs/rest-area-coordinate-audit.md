## 재실행

```powershell
node scripts/sync-rest-areas.mjs --csv "<CSV 경로>" --geocode --allow-partial-services
node scripts/sync-rest-areas.mjs --csv "<CSV 경로>" --geocode --allow-partial-services --apply
```

--apply가 없으면 DB는 읽기만 합니다. 조회 장애가 있는 편의시설 API는 명시적으로 --allow-partial-services를 선택했을 때에만 확보한 정보를 보강합니다. 완전한 기준정보·상세 편의시설 수집과 기존 행 보존은 필수입니다.
