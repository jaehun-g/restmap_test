# 미해결 항목

2026-11-12 한국시간 기준 로컬 코드와 설정된 DB를 읽기 전용으로 대조했다. DB 수치는 이후 동기화로 바뀔 수 있다. 현장·실제 배포·Vercel 실행 주체는 별도 확인이 필요하며 후보나 표기 차이만으로 오류라고 단정하지 않는다.

## 노선과 방향

- [ ] **방향 선택지 정리:** 2026-11-12 기준 세 방향 이상인 노선의 실제 구간과 원천 표기를 대조한다. 남해선(부산·순천·영암), 당진영덕선(당진·대전·상주·영덕·청원·청주), 동해선(동해·삼척·속초·울산·포항), 순천완주선(광양·순천·완주·전주), 함양울산선(밀양·울산·함양)이 대상이다. 앱의 별칭 통합 후 집계이며 전체 방향과 양방향은 제외했다. 휴게소·주유소 매칭과 재동기화 유지 여부도 확인한다.
- [ ] **밀양영남루:** 휴게소·주유소의 함양·밀양 방향 위치와 연결을 지도에서 확인한다. 원천의 밀양·울산 표기가 달라 실제 진입 방향은 미확인이다.
- [ ] **반대 방향 연결:** 선산·문경·서여주·부여백제 휴게소와 연결 주유소의 이름·방향·위치·유가를 확인한다. 원천 방향과 주유소 이름이 충돌한 이력이 있다.
- [ ] **진행 방향 규칙:** 현재 DB 247건은 상행 96·하행 98·양방향 14·NULL 39건이다. `lg_direction_label`과 분리된 이 규칙이 재수집과 관리자 입력, 배포 후에도 유지되는지 확인한다.
- [ ] **선형 품질:** 2026-10-20 조사에서 일부 경로의 인접 점 간격과 저장 경계값, 선형 원본 출처·라이선스·변환 이력이 불충분했다. 이후 변경분을 재조회하고 필요한 구간의 원본 보강, 경계값 및 실제 지도 중첩을 검증한다.

## 휴게소와 EX 주유소

- [ ] **미연결 주유소:** 현재 EX 주유소 226곳 중 224곳이 로컬 매칭 규칙에서 연결되고 성남(구리), 구리남양주(판교) 2곳이 미연결이다. 대응 휴게소·방향·좌표를 확인한다. 김해금관가야(기장)는 현재 양방향 휴게소에 연결된다.
- [ ] **주유소 유무 미확인 휴게소:** 현재 연결 주유소가 없는 휴게소 31곳 중 30곳은 주유소 유무가 미확인이며 순천(순천)은 없음으로 등록돼 있다. 실제 시설 유무를 확인한다.
- [ ] **누락 좌표:** 현재 점곡(상주 방향), 군자행복드림쉼터, 구리남양주행복드림쉼터의 좌표가 없다. 실제 위치와 방향을 확인한다.
- [ ] **기존 좌표 보정:** 휴게소 좌표에 맞춘 주유소 21곳은 주유기·건물의 실제 위치를 확인한 좌표가 아니므로 필요한 경우 현장·지도 자료와 대조한다.
- [ ] **EX·GS 중복 후보:** 2026-10-15 전화번호가 일치한 15쌍은 이름·주소·좌표 검증 없이 식별된 후보이므로 동일 시설이라고 단정하지 말고 필요 시 재검토한다.
- [ ] **가격과 배포:** 언양(서울)의 유효 가격 제공 여부, 서하남 인포윈도우 가격 표시, 방향·연결 보정 코드의 운영 배포 및 다음 가격·음식 Cron 실행을 확인한다. 과거 DB 기록만으로 Cron 실행 여부는 확정되지 않았다.

## 음식 데이터

- [ ] **휴게소 매핑:** 현재 원천 코드 240개 중 214개가 연결됐고 26개가 미연결이다. 미연결 중 21개는 제외된 민자 휴게소이며, 나머지 기흥복합 `000408`, 논공 `000446`·`000447`, 함양 `000551`·`000552` 5개는 동일 시설 여부와 중복 코드·운영 이력을 확인한다.
- [ ] **명칭 이력:** 여산(순천)과 익산미륵사지의 전화번호·좌표·방향 일치로 연결한 건은 실제 명칭 변경 이력을 확인한다.

## 운영 화면

- [ ] 실제 휴대폰에서 지도 첫 접속·재접속, 확대·축소, 반경 변경, 전체화면과 상세 화면을 확인한다.
- [ ] 디자인 시스템 전체 테스트에서 사용처가 없는 `map-hint` 기준 항목을 정리한다. 현재 일부 공통 컨트롤 테스트는 통과하지만 전체 기준 테스트는 해당 항목에서 실패한다.
