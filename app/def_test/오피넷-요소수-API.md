# 오피넷 요소수 가격 API

확인일: 2026-11-10. 아래 내용은 오피넷 공식 안내와 이 프로젝트의 로컬 테스트 결과를 구분해 정리했다.

## 엔드포인트

```text
GET https://www.opinet.co.kr/api/ureaPrice.do
```

지역별 요소수 판매 주유소의 가격과 재고 여부를 제공한다. 주유소별 응답이며 평균가격이나 전일 대비 등락값은 제공하지 않는다. [공식 API 명세](https://www.opinet.co.kr/user/custapi/openApiInfoDtl.do?apiId=8)

## 요청 방법

| 파라미터 | 설명 |
| --- | --- |
| `code` | 오피넷 인증키. 현재 로컬 테스트에서 정상 동작한 이름 |
| `out` | 응답 형식 `json` 또는 `xml` |
| `area` | 두 자리 지역 코드. 예: 경기 `02`, 전남·광주 `20` |

```text
GET https://www.opinet.co.kr/api/ureaPrice.do?out=json&area=02&code=인증키
```

공식 명세는 인증키 파라미터를 `certkey`로 안내한다. 그러나 2026-11-10 로컬 테스트에서는 `certkey` 요청이 빈 배열을 반환했고 `code` 요청으로 데이터가 반환됐다. 운영 적용 전에는 명세와 실제 동작의 차이를 오피넷에 확인해야 한다.

공식 명세상 `area`는 선택값이지만, 같은 날 `area` 생략과 `area=00` 요청은 모두 HTTP 200과 빈 배열을 반환했다. `area=00`이 공식 전국 코드라고 확인된 것은 아니다. 이 시험에서는 지역 코드 16개를 각각 조회해 전국 평균을 계산한다.

로컬 환경에서는 프로젝트 루트의 `.env.local`에 `OPINET_API_KEY=인증키`를 설정한다. 브라우저는 서버의 `/def_test/api?area=02`를 호출하며 인증키는 서버에서 사용한다.

## 응답

오피넷 원본의 구조를 설명하기 위한 예시다. 각 `OIL` 항목은 주유소 하나를 뜻한다.

```json
{
  "RESULT": {
    "OIL": [
      {
        "UNI_ID": "주유소 코드",
        "OS_NM": "주유소명",
        "ADR": "주소",
        "TEL": "전화번호",
        "GIS_X_COOR": "X좌표",
        "GIS_Y_COOR": "Y좌표",
        "STOCK_YN": "Y",
        "PRICE": "1500",
        "TRADE_DT": "20261110",
        "TRADE_TM": "093000"
      }
    ]
  }
}
```

| 필드 | 의미 |
| --- | --- |
| `UNI_ID`, `OS_NM` | 주유소 코드와 상호 |
| `ADR`, `TEL` | 주소와 전화번호. 공식 반환값 표에는 주소가 `ADRESS`로 표기되지만 공식 예시와 테스트 응답은 `ADR` 사용 |
| `GIS_X_COOR`, `GIS_Y_COOR` | KATEC 좌표 |
| `STOCK_YN` | 재고 여부 `Y`/`N` |
| `PRICE` | 요소수 판매단가, 원/리터 |
| `TRADE_DT`, `TRADE_TM` | 보고일자와 보고시각 |

로컬 테스트에서 JSON의 문자열 내부에 줄바꿈이 포함되어 일반 JSON 파싱이 실패했다. 시험 코드는 이를 정규화한 후 파싱한다. 집계에는 `PRICE`만 사용하며 유효한 양수 가격의 단순 평균을 계산한다. 재고 여부와 보고일자는 필터링하지 않는다.

시험용 서버 응답은 `regional`, `national`, `retrievedAt`, `opinetStatus`, `opinetResponse`를 포함한다. `opinetResponse`는 선택 지역의 파싱된 응답이며 바이트 단위 원문은 아니다. `retrievedAt`은 시험 서버의 응답 시각으로, 오피넷의 마지막 갱신 시각을 뜻하지 않는다. 전일 대비는 제공되지 않으며, 화면에는 경기 1,650원·전국 1,580원의 이전 가격 목업을 사용한다.

## 데이터 갱신 주기와 시간

공식 명세는 `PRICE`의 업데이트 시각을 하루 네 차례 **07:00, 13:00, 18:00, 24:00**으로 안내한다. 한국 시간으로 해석하되, 공식 명세에는 시간대가 별도로 명시되어 있지 않다. 개별 주유소의 보고일시가 API 갱신 시각과 같다는 뜻은 아니다. [공식 API 명세](https://www.opinet.co.kr/user/custapi/openApiInfoDtl.do?apiId=8)

현재 시험 코드는 지역별 오피넷 응답에 최대 4시간의 재검증 캐시를 설정한다. 따라서 화면 조회 시각은 원본 가격의 갱신 시각과 다를 수 있으며, 캐시는 위 네 시각에 맞춰 자동 실행되는 스케줄러가 아니다.

## 일별 호출 횟수

오피넷 안내상 일반 API는 기본 **하루 300회**, 프리미엄 API는 **하루 1,500회**다. 일반 API에서 하루 1,500회 호출을 희망하면 기업·기관 제휴가 필요하다고 안내한다. 실제 적용 범위와 초기화 시각은 안내 페이지에 명시되지 않아 오피넷에 확인해야 한다. [오피넷 API 이용 안내](https://www.opinet.co.kr/user/custapi/custApiInfo.do)

현재 전국 집계는 캐시가 없을 때 지역별로 최대 16회 호출한다. 지역별 응답의 캐시가 유효하면 지역 선택을 다시 해도 캐시를 사용할 수 있다. 서버 재시작, 배포 환경, 캐시 만료 및 실패·재시도에 따라 실제 호출 횟수는 달라질 수 있다.
